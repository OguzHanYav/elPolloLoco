## 📋 Projektübersicht

**elPolloLoco** ist ein browserbasiertes Jump 'n' Run-Spiel mit spritebasierter Animation, Kollisionserkennung und responsiven Steuerelementen für Desktop- und mobile Endgeräte. Das Projekt folgt objektorientierten Programmierprinzipien und ist vollständig mit JSDoc dokumentiert.

### Kernfunktionen

| Funktion | Beschreibung |
|----------|---------------|
| 🎮 **Canvas-basiertes Rendering** | Flüssiges 60-FPS-Gameplay über HTML5 Canvas |
| 🔊 **Audio-Subsystem** | Hintergrundmusik + situationsbezogene Soundeffekte (Tod, Spritzer) |
| 📱 **Multi-Device-Support** | Tastatur für Desktop, Touch-Buttons für mobile Geräte |
| 🐞 **Fehlerfreies Gameplay** | Umfangreiches Offset-Tuning und optimierte Event-Behandlung |
| 📘 **JSDoc-Dokumentation** | Vollständig dokumentierter Code für Wartbarkeit |
